AntryGravity API

The AntryGravity API gives you programmatic access to our AI background removal, image upscaling, and background generation capabilities. Build powerful image processing pipelines directly into your applications.

API Key Required
API access requires a Business or Enterprise plan. View plans →
Get API Key
Base URL
https://api.antrygravity.com/v1
Quick Example
shell 
# Remove background from an image
curl -X POST 'https://api.antrygravity.com/v1/remove-background' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -F 'image=@/path/to/your/image.jpg' \
  -o result.png

Authentication

All API requests must be authenticated using your API key as a Bearer token in the Authorization header. Never expose your API key in client-side code.

HTTP Header
Authorization: Bearer ag_live_xxxxxxxxxxxxxxxxxxxxxxxx
Generating API Keys

Create and manage API keys from your dashboard. You can create multiple keys for different applications and revoke them at any time. Keys are prefixed with ag_live_ for production and ag_test_ for testing.

Remove Background

POST /v1/remove-background Remove background from an image
Request Parameters
ParameterTypeRequiredDescription
imagefileRequiredImage file (JPG, PNG, WEBP, max 25MB)
output_formatstringOptionalpng (default), webp
qualityintegerOptionalOutput quality 1-100 (default: 90)
refine_edgesbooleanOptionalEnable fine edge refine (costs +1 credit)
webhook_urlstringOptionalURL to receive async callback
Example Response
{
  "job_id": "job_abc123",
  "status": "completed",
  "credits_used": 1,
  "output_url": "https://api.antrygravity.com/v1/results/job_abc123.png",
  "expires_at": "2026-09-20T23:59:59Z"
}

Upscale Image

POST /v1/upscale Upscale image up to 8K
ParameterTypeRequiredDescription
imagefileRequiredImage file to upscale
scalestringOptional2k, 4k, 8k (default: 2k)
denoiseintegerOptionalNoise reduction 0-100 (default: 30)
sharpnessintegerOptionalSharpness 0-100 (default: 70)

Error Handling

All errors return a JSON object with an error field. HTTP status codes follow standard REST conventions.

{
  "error": {
    "code": "insufficient_credits",
    "message": "You don't have enough credits for this operation.",
    "status": 402
  }
}
Common Error Codes
StatusCodeMeaning
401unauthorizedInvalid or missing API key
402insufficient_creditsNot enough credits
413file_too_largeFile exceeds maximum size
422invalid_imageUnsupported or corrupt image
429rate_limit_exceededToo many requests
500server_errorInternal server error

JavaScript SDK

shell — Install
npm install @antrygravity/sdk
JavaScript — Usage
// ⚠️ Store your API key server-side, never in browser code
const { AntryGravity } = require('@antrygravity/sdk');

const client = new AntryGravity({
  apiKey: process.env.ANTRYGRAVITY_API_KEY,
});

const result = await client.removeBackground({
  image: fs.createReadStream('./photo.jpg'),
  outputFormat: 'png',
  refineEdges: true,
});

console.log(result.outputUrl); // Download URL
