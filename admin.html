Setup Guide
  1. Create a backend server (Node.js, Python, etc.)
  2. Sign up for an AI provider (Remove.bg, Clipdrop, etc.)
  3. Store the API key as an environment variable
  4. Create a proxy endpoint on your backend
  5. Enter the proxy endpoint URL in this form
  6. Click "Test Connection" to verify
